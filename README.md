# Where did the tokens go

Count your own Claude Code, Codex and Cursor token use, on your own machine. Get a terminal report and a private dashboard on localhost that shows which project each cost belongs to, and says **unknown** where there is no evidence.

- **Private by design.** It reads the logs your agents already keep. Nothing is uploaded. No account, no telemetry, no network calls. The dashboard listens on 127.0.0.1 only.
- **Honest numbers.** Dollars are an estimate at public list price, never "what you paid". A model with no known price shows as "no price", never as zero. Unknown is drawn on the chart, never dropped.
- **No config needed.** Zero dependencies beyond Python 3.9.

## Install and run

You need Python 3.9 or newer. The package is not on PyPI, so every command installs from this GitHub repo.

With [uv](https://docs.astral.sh/uv/):

```
uvx --from git+https://github.com/Morkeeth/token-inventory tokens serve --open
```

or install it once with pipx:

```
pipx install git+https://github.com/Morkeeth/token-inventory
tokens scan
tokens report
tokens serve --open
```

No uv or pipx? Use a checkout. It needs nothing beyond Python:

```
git clone https://github.com/Morkeeth/token-inventory
cd token-inventory
python3 -m wheretokens serve --open
```

## Commands

| Command | What it does |
|---|---|
| `tokens scan` | Reads your local records and writes the inventory. `--days N` reads only recent days |
| `tokens report` | Prints tools, projects and the unknown share. `--days 30`, `--days 0` for all time, `--json` |
| `tokens serve` | The dashboard on http://127.0.0.1:7788. `--port`, `--open`. Ctrl-C stops it |
| `tokens import-cursor FILE.csv` | Adds a Cursor usage export you downloaded |
| `tokens where` | Every folder it reads and writes |
| `tokens config` | Where the optional config lives, with an example |

## What it reads, writes and sends

| | |
|---|---|
| Reads | `~/.claude/projects` (Claude Code), `~/.codex/sessions` and `~/.codex/archived_sessions` (Codex), a Cursor CSV only if you import one. Only timestamps, message ids, model names, token counters and folder names. Never prompt text, replies, file contents or tool results |
| Writes | `~/.local/share/where-did-the-tokens-go/`: daily sums per tool, project and model. Delete the folder to remove everything |
| Sends | Nothing |

`CLAUDE_CONFIG_DIR`, `CODEX_HOME`, `XDG_DATA_HOME` and `TOKENS_DATA` are respected.

## Projects and unknown

A cost gets a project for one stated reason, first match wins: **your rule**, then the **working folder**, then the **files touched** when the folder says nothing, else **unknown**. Start your agents inside a project folder and most of it is placed for you.

To place the rest, add rules. `tokens config` shows the path. Example:

```
{
  "code_roots": ["~/code", "~/work"],
  "rules": [
    {"match": "~/work/client-a/*", "project": "Client A"},
    {"match": "~/notes", "project": "Writing"}
  ],
  "prices": {"claude": {"some-new-model": [3.0, 15.0]}}
}
```

## Limits

- Three sources: Claude Code, Codex, and Cursor through its export. Other tools keep no local counters and are not counted.
- Estimates use list prices dated 2026-10-04. Prices change.
- Compressed `.jsonl.zst` transcripts are not read.
